How to Run Locally & Push to GitHub

Simple standalone workflow for your 12-hour GPS Slicer

Step 1: Save the File

Save this complete code as index.html.

Step 2: Run Locally

Double click index.html to open it in Chrome, Edge, Safari, or Firefox.

python -m http.server 8000

Open http://localhost:8000 in your browser.

Step 3: Push to GitHub

git init

git add index.html

git commit -m "feat: 12-hour AM/PM GPS track slicer for VIRB Edit"

git branch -M main

git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

git push -u origin main

Step 4: Enable GitHub Pages

Go to your GitHub repo → Settings → Pages → set Branch to main → Save. Your app will be live at https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/.
